# wysiwyg

A JavaScript WYSIWYG editor built on the browser's `contenteditable` attribute.

This project is at the very start. The repository holds only this README so far, and the editor itself will land in later commits.

## Goals

- Edit rich text directly in the page using `contenteditable`.
- Ship as a small, dependency-light JavaScript library.
- Produce clean, predictable HTML.

## Status

Early planning. Nothing is usable yet.
